Module 1 · Sorting

Sort by quantity, then by location

Click a column header to sort by it. Shift-click a second header to add it as a tie-breaker for rows where the first column matches. Click a header again to flip ascending/descending.

Module 3 · Looking Up Values (LOOKUP)

Cross-reference against a customer list

The customer list on the left (columns A-B) and the invoices on the right (columns D-F) live on the same sheet. Use LOOKUP(value, lookupRange, resultRange) to pull each invoice's customer name from its Customer ID — the same idea as a hash-map lookup, expressed as a spreadsheet formula.

Module 4 · Data Validation — Restricting Entry

Make it impossible to enter the wrong thing

A dropdown only offers valid choices. A range restriction rejects a number that's out of bounds. Both of these fields below are locked down that way — try to break them, then fix them.

The Status field only allows Present / Absent / Late (try opening the dropdown — nothing else is even an option). The Quantity field only allows 0–500 — it currently holds an out-of-range test value. Set it to a valid number to continue.
