Module 1 · Aggregate Functions: SUM & AVERAGE

Add it up, then find the average

Two records, same two functions. SUM(range) adds every number in a range; AVERAGE(range) divides that sum by how many numbers there are.

Module 2 · Aggregate Functions: MIN, MAX, COUNT, COUNTA

Find extremes, and count what's actually there

MAX/MIN find the highest/lowest number in a range. COUNT counts only numeric cells; COUNTA counts every non-blank cell, numbers or text. They're not the same — watch what happens with a text entry mixed into a number column.

Module 5 · Conditional Aggregates: COUNTIF & SUMIF

Count or sum only what matches

COUNTIF(range, criteria) counts matching cells; SUMIF(range, criteria, sumRange) sums a parallel range wherever the criteria matches. Criteria can be a plain value ("Late") or a comparison (">10000").
