Module 4 · Relative vs. Absolute References

One tax rate, many line items

Cell F1 holds this invoice's tax rate — one fixed number every line item needs. If you reference it normally (F1) and later copy the formula to another row, the reference would drift. Lock it with dollar signs ($F$1) so it stays put no matter where the formula goes.

Module 5 · AutoFill / Fill-Down

Write it once, fill it down the column

This inventory log needs the same formula on every row: units received minus the reorder buffer in E1. Write it once in row 2, then drag the small handle at the corner of the cell down the column — or use the Fill Down button — and watch the relative reference update on its own while $E$1 stays fixed.
